# Ghost Sparkle Updates

Ghost uses Sparkle 2 for direct-download macOS updates.

## One-Time Setup

1. Download Sparkle 2 from https://sparkle-project.org.

2. Generate your Sparkle EdDSA key:

   ```bash
   /path/to/Sparkle/bin/generate_keys
   ```

   Keep the private key in your Keychain. Save the printed public key.

3. Choose the HTTPS URL where updates will live:

   ```text
   https://yourdomain.com/ghost/appcast.xml
   ```

4. For every release command, set:

   ```bash
   export SPARKLE_FEED_URL="https://yourdomain.com/ghost/appcast.xml"
   export SPARKLE_PUBLIC_ED_KEY="public-key-from-generate_keys"
   export SPARKLE_TOOLS_DIR="/path/to/Sparkle/bin"
   ```

## Build A Release

Each release needs a user-visible version and an increasing build number.

```bash
export GHOST_VERSION="1.0.1"
export GHOST_BUILD="101"
export SPARKLE_FEED_URL="https://yourdomain.com/ghost/appcast.xml"
export SPARKLE_PUBLIC_ED_KEY="public-key-from-generate_keys"
export SPARKLE_TOOLS_DIR="/path/to/Sparkle/bin"

./script/package_release.sh
```

This creates:

```text
releases/ghost/Ghost-1.0.1.zip
releases/ghost/appcast.xml
```

If you have Developer ID signing set up, add:

```bash
export DEVELOPER_ID_APPLICATION="Developer ID Application: Your Name (TEAMID)"
```

If you have a notarytool keychain profile set up, add:

```bash
export NOTARY_PROFILE="your-notarytool-profile"
```

## Publish The Update

Upload everything in `releases/ghost/` to your update host so these URLs work:

```text
https://yourdomain.com/ghost/appcast.xml
https://yourdomain.com/ghost/Ghost-1.0.1.zip
```

Users who already have Ghost installed can choose:

```text
More -> Check for Updates...
```

Sparkle will compare their installed `CFBundleVersion` with the newest build in
the appcast. If the appcast build is newer, Sparkle shows the update dialog.

## Test An Update

1. Install an older Ghost build, for example `GHOST_BUILD=100`.
2. Publish a newer build, for example `GHOST_BUILD=101`.
3. Open Ghost.
4. Choose `More -> Check for Updates...`.

To reset Sparkle's last-check cache during testing:

```bash
defaults delete com.local.Ghost SULastCheckTime 2>/dev/null || true
```

## Important Rules

- Always increase `GHOST_BUILD`.
- Keep `SPARKLE_PUBLIC_ED_KEY` stable after users receive a build.
- Do not lose the private key generated by Sparkle.
- Ship signed and notarized releases for public distribution.
- Keep `SPARKLE_FEED_URL` hosted over HTTPS.
