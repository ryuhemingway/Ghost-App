How it works

Ask once.
Ghost handles the rest.

01

Open Ghost

Summon it from the menu bar or press Option-Space from anywhere on your Mac.

02

Ghost routes the prompt

Provider, model, and engine are chosen automatically — Direct API for fast answers, the agent path for files, code, and multi-step work.

03

Context is retrieved

When a prompt needs local knowledge, Ghost queries your private RAG index for cited, source-backed chunks.

04

Actions are verified

The capability harness validates, runs, and returns the real result — not a model claim — for files, conversions, and Mac integrations.

Privacy

Local-first by default.

Ghost separates local providers, local indexes, and hosted key paths — so privacy is a routing choice, not an afterthought. Your RAG index lives in a local SQLite database, and provider secrets stay scoped to the routes you choose.

  • ✓ Local models and local retrieval keep traffic on your Mac.
  • ✓ Secrets are loaded from Ghost's local env store and filtered by provider.
  • ✓ Higher-risk actions require explicit approval paths.
