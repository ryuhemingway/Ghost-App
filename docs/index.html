01 What it does

Ask it.
It does the work.

All of this happens in the same bar under your notch, inside the apps and files you already use.

Any model

Use any model, including the plan you already pay for

Run Ghost on your Claude Code, Codex or Antigravity plan, on an API key for Claude, Gemini, DeepSeek or any OpenAI-compatible server, or on a model in LM Studio or Ollama that never leaves your Mac. You switch between them from one menu.

Documents and files

It makes the file, and it can take it back

Ask for a PDF, a Word document, a slide deck, a spreadsheet or a web page and Ghost saves it where you ask, such as your Desktop. Every file Ghost makes, moves or edits gets an Undo button, and by default it asks before it changes anything.

Your day

Plans, reminders and texts in plain words

Type “lunch with Sam Friday at 1pm” and the event goes into whichever calendar you name, Google calendars included. Reminders and notes work the same way with Undo, and “text mom: running late” finds the right contact and asks before it sends.

Your documents

Answers from your own files, with the page they came from

Point Ghost at a folder and it builds a search index on your Mac. Each answer names the file and page it used, and one click opens it. Tell it “when I ask about my classes, read timetable.xlsx” and it reads that file every time.

Your screen

Show it what you are looking at

Paste a screenshot with ⌘V, or capture the whole screen with one button, and ask about it. Drag over any part of the screen and Ghost reads the text off it in about a tenth of a second, on your Mac.

Coding agents

Every coding agent on your Mac, in one list

Claude Code, Codex, opencode and DeepSeek Harness sessions from any terminal show up in the Agents tab, and when one needs permission it asks you from the notch. You can chat with Claude, Codex or opencode right there, give Claude a subagent on another model, and see what each task cost and which files it changed.

02 Privacy

Private
by default.

Ghost can reach a lot of your Mac, so you decide how much. Your API keys stay in the macOS Keychain, and every release is notarized by Apple.

Everything starts off

Web, files, Mac automation, Messages, screen capture and the terminal are six separate switches, and each stays off until you turn it on.

Personal data stays on your Mac

Messages, Notes, Mail and Contacts are only ever read by a model running on your Mac. Ghost refuses to pass them to a cloud one.

Rules it cannot talk its way past

Write a boundary once, such as a folder Ghost must never touch, and it is checked before every action. The action log shows what Ghost tried, what you allowed and what it refused.
