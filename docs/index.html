What Ghost provides

Your Mac, your models, your context.

Ghost lives in the menu bar and opens with a fast glass panel or a terminal-grade coding view. It can answer directly through provider APIs, hand off deeper work to a local agent, ground responses in your documents, and verify local actions before the model gets credit for doing anything.

Agent router

Choose Direct API speed or full agent depth.

Ghost can call provider APIs directly for fast answers, or launch a connected Ghost/Hermes agent for multi-turn local work, approvals, toolsets, and coding tasks.

Local models

LM Studio and Ollama stay local.

Local providers route through Ghost's managed OpenAI-compatible tool loop, with provider isolation that prevents accidental cloud-agent launches.

Cloud models

Bring Claude, Gemini, or DeepSeek.

Save provider keys once, pick the model and effort level, then let Ghost handle the prompt, streaming, and routing details.

Workspace tools

Read, create, convert, open, and organize files.

Ghost exposes verified file tools for documents, markdown, HTML, CSV, JSON, PDF, DOCX, PPTX, XLSX, folders, Finder reveal, and safe metadata inspection.

Native actions

Calendar, reminders, voice, and web search.

Ask for reminders, calendar events, calendar lookups, dictated prompts, web context, and read-only shell checks without leaving the panel.

Capability harness

The model requests. Ghost verifies.

The harness is Ghost's safety and truth layer. Models ask for capabilities by name, but Ghost normalizes paths, blocks sensitive files, checks allowed roots, performs the action, and returns a machine-readable result. User-visible confirmation is based on verified results, not model claims.

01 Normalize

Resolve workspace, Desktop, Documents, Downloads, and Ghost Outputs safely.

02 Gate

Apply risk levels, sensitive-path blocking, and read/write boundaries.

03 Execute

Create, convert, query, open, reveal, sync, or inspect through native macOS APIs.

04 Verify

Return structured evidence so the transcript reflects what happened.

Ghost RAG

Turn your files into cited working memory.

Ghost indexes allowed local documents into a SQLite-backed retrieval store, extracts text, chunks it, and answers with source-backed context.

Ingest

Index a file, folder, or synced folder from your workspace or common user folders.

Retrieve

Query cited chunks, search excerpts, inspect RAG status, or open a source document.

Maintain

Reindex, remove documents, or clear the index without deleting the original files.
