product promise

An operating layer for models, files, agents, and verified work.

Ghost is built for the moment after the chatbot novelty wears off: when you need AI to understand private context, choose the right execution path, touch real local tools, and prove what happened. It keeps the interface quiet while the routing layer does the serious work underneath.

trust engine

The model can ask. Ghost decides.

The capability harness is the boundary between language and your Mac. It resolves allowed roots, blocks sensitive paths, applies risk levels, performs the requested operation, and returns a receipt the interface can trust.

01 Normalize

Resolve workspace, Desktop, Documents, Downloads, and Ghost Outputs safely.

02 Gate

Apply risk levels, sensitive-path blocking, and read/write boundaries.

03 Execute

Create, convert, query, open, reveal, sync, or inspect through native APIs.

04 Verify

Return structured evidence so the transcript reflects what happened.

launch sequence

From clean clone to private command center.

  1. 01 Clone gh repo clone ryuhemingway/Ghost-App
  2. 02 Build cd Ghost-App && swift build
  3. 03 Run ./script/build_and_run.sh
  4. 04 Connect providers LM Studio, Ollama, Claude, Gemini, or DeepSeek
  5. 05 Configure agent ~/.local/bin/ghost or ~/.local/bin/hermes
  6. 06 Enable RAG Index files, sync folders, query cited chunks
  7. 07 Start working Route, retrieve, verify, act
