# Ghost App Visuals

Native macOS app screenshots captured from the current Ghost build, shot against
a bare desktop so nothing but Ghost's own glass is in frame.

```text
notch-hero.png      an answer in the notch, with provider / model / timing chips
quick-ask.png       the resting composer hanging from the notch
model-routing.png   the AI settings page: model, provider, routing
privacy-access.png  the Privacy & Access page, one switch per capability
terminal.png        the Terminal section
settings.png        the General settings page
```

The remaining product screenshots live in `assets/` at the repository root
(pomodoro and study record, focus sessions, cited answers, research, inline
imagery, local file access).

Captured 2026-08-09. Earlier files showing surfaces the app no longer has (the
old main panel, the command palette, the Ghost Code screens, the standalone RAG
task view) were removed rather than left to rot.
