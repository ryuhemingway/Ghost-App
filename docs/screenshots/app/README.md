# Ghost App Visuals

Full-screen captures from the current Ghost build, shot on a bare desktop so you
can see how the app actually sits on a laptop when it is summoned — nothing else
on screen but the wallpaper.

```text
quick-ask.jpg       Ghost at rest, hanging from the camera notch
model-routing.jpg   the AI settings page: model, provider, routing
privacy-access.jpg  the Privacy & Access page, one switch per capability
terminal.jpg        the Terminal section
settings.jpg        the General settings page
```

The rest of the product screenshots sit in `docs/` alongside the landing page:
the hero answer, Saturn, the cited web answer, the file listing, the pomodoro and
its study record, and the two rewrite shots.

Captured 2026-08-09 at 2400px, JPEG, from the built-in Retina display. Earlier
files showing surfaces the app no longer presents (the old main panel, the
command palette, the Ghost Code screens, the standalone RAG task view) were
removed rather than left to rot.
